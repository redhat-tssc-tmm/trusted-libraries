# Overview

This top-level directory contains some helper scripts to assess the current state of Trusted Libraries (how many, which carry attestations, etc). 

For end-to-end verification scripts, please go to the [./blog/scripts](./blog/scripts) directory and see the [README](./blog/scripts/README.md) there.

These scripts accompany this blog post https://developers.redhat.com/blog/2026/02/27/red-hat-trusted-libraries-trust-and-integrity-your-software-supply-chain#
